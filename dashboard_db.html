About this dashboard

This dashboard visualizes team-level season performance for women's NCAA basketball, pulled live from a database of game-by-game box scores.

What's in the data

  • Season summary — record, win rate, points for/against, shooting splits, rebounds, assists, turnovers, steals and blocks, each averaged per game.
  • League-wide win drivers — every team's win % plotted against its scoring offense and scoring defense, with a correlation coefficient for each, to compare which matters more for winning.
  • Home/away record — win % split by venue.
  • Game log — every game the selected team played that season, with date, opponent, score and result.

How to use it

Pick a season, then start typing a college name in the search box — matching results filter instantly as you type. Every tab updates to reflect your current season/team selection.

Color key

Orange marks points for / field goal percentage, gray marks points against, tan marks three-point percentage, green marks wins and free throw percentage, and red marks losses.
